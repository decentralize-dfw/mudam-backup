# Önceki etütler

Bu dosyalar geçerli teslim değildir. P03 v001 alt kat izleri ve kaynak kimlikleri düzeltilmeden önceki sürümdür; kullanılmamalı. P04 v001 kat bölgesi çizgileri iyileştirilmeden önceki sürümdür. Güncel v002 dosyaları üst klasördedir.

P05 v001, yan cam örtü eğim yönleri ve çatı boşlukları düzeltilmeden önceki etüttür; kullanılmamalı. P05 v002 günceldir.
